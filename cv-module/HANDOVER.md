# CV Module Handover Notes

## Current Status
The CV module is integrated with `assistant_core` and the Flask API.
Face detection and rule-based image classification have been implemented and tested.

## Future Improvements

### Face Detection Accuracy
- Replace Haar Cascade with a more advanced deep learning-based face detector.
- Improve detection accuracy for side profiles and small faces.

### Confidence Score
- Develop a more accurate confidence score calculation instead of fixed values.

### Real-Time Detection
- Add support for real-time face detection using camera/video input.

### Image Classification
- Explore advanced deep learning models for image classification instead of rule-based classification.
